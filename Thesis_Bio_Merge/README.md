# Plasma-Radiobiology Thesis Draft

## Title

**Biological Implications of Suppressing Radiation Emissions from Relativistic Plasmas Using Magnetic Perturbations: A Multiscale Framework for Source-Term Control, Dosimetry, and Radiobiological Risk**

## Contents

- `main.tex` - master LaTeX document and front matter
- `chapters/` - eleven thesis chapters and three appendices
- `references.bib` - BibLaTeX database
- `figures/` - generated PDF and PNG figures
- `scripts/illustrative_model.py` - reproducible illustrative calculations
- `illustrative_results.csv` - numerical output from the illustrative model
- `main.pdf` - compiled thesis preview

## Compilation

A current TeX Live installation with `latexmk` and `biber` is recommended.

```bash
latexmk -pdf -interaction=nonstopmode main.tex
```

To clean generated auxiliary files:

```bash
latexmk -C
```

## Scientific status of the draft

This document is a complete integrated theoretical and methodological thesis draft. Chapter 8 contains explicitly labeled illustrative calculations generated by the included Python script. These calculations demonstrate the proposed analysis chain but are not presented as experimental measurements or validated device predictions. Device-specific parameters, measured spectra, transport simulations, dosimeter readings, biological assay data, institutional formatting, committee information, and approval details must be replaced or completed before submission.

## Reproducing the illustrative figures

From the project root:

```bash
python scripts/illustrative_model.py
```

The script regenerates the illustrative CSV and the figures used in Chapter 8.
